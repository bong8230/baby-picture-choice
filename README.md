# baby-picture-choice

아기 앨범에 넣을 사진을 고르기 어려울 때 쓰는 앱입니다.
한 주 동안 찍은 사진 중 후보를 올리면, 부부가 각자 휴대폰에서 토너먼트로 투표해 그 주의 사진 1~3장을 고릅니다.
고른 사진의 원본은 PC에 저장되어, 나중에 앨범 업체에 그대로 보낼 수 있습니다.

PC에서 Node 서버(127.0.0.1:8790, 런타임 의존성 없음)를 실행하고 Tailscale로 휴대폰에서 접속합니다.

## 주요 기능

- **주차 자동 분류**: 사진의 촬영 날짜(EXIF)를 읽어 `2026년 11월 4주차`처럼 주차별로 나눕니다. 달에 걸친 주는 그 주 목요일이 속한 달로 셉니다.
- **아기 생후일 표시**: 관리 화면에 아기 생일을 넣으면 주차마다 `생후 72~78일 · 11주차`, 사진마다 `생후 75일`을 보여줍니다.
- **흔들린 사진·중복 사진 거르기**: 휴대폰 브라우저 안에서 선명도, 비슷한 사진, 얼굴(눈 뜸·웃음)을 분석합니다. 얼굴 점수는 약하게만 반영합니다. 사진은 외부로 보내지 않습니다.
- **HEIC 지원**: 갤럭시 카메라의 HEIC 사진을 휴대폰에서 원본 해상도 JPG로 바꿔 저장합니다. HEIC 원본도 함께 보관합니다.
- **토너먼트 투표**: 나와 아내가 각자 링크로 들어가 두 장씩 비교하며 1~3위를 고릅니다.
- **결과 합치기**: 두 사람 모두 3위 안에 넣은 사진만 저장합니다. 겹치는 사진이 없으면 각자의 1위끼리 `함께 결승`을 합니다.
- **최종 저장**: 고른 사진은 `selected/2026-11월4주차_1.jpg` 형식으로 저장됩니다.
- **한 주 최대 16장**: 16장을 넘기면 해당 주에 경고가 뜨고, 2일 안에 줄이지 않으면 점수가 낮은 사진부터 자동 삭제합니다. PC에 올라간 사본만 지우며 휴대폰 원본은 그대로입니다.
- **갤러리에서 공유로 올리기**: 관리 화면을 앱으로 설치하면 삼성 갤러리에서 사진을 골라 `공유 → 아기사진`으로 바로 올릴 수 있습니다.

## 접속과 보안

- 관리 화면은 Tailscale에 로그인한 본인(`config.json`의 `adminLogin`)만 열 수 있습니다.
- 아내는 Tailscale 없이 투표 링크로 들어옵니다. 이 링크는 Tailscale Funnel로 투표 기간에만 공개합니다.
- 공개 접속으로는 투표 화면만 열리고, 관리 화면·사진 원본·설정은 모두 막혀 있습니다.
- 투표 링크는 사람마다 다른 추측 불가능한 주소이며, 투표가 끝나고 Funnel을 끄면 폐기됩니다.

## 폴더 구성

- `server.js`, `src/` : 서버(접속 권한, 업로드, 투표, 저장)
- `public/` : 휴대폰 화면(관리, 투표, 사진 분석, HEIC 변환)
- `scripts/funnel.js` : 공개 접속 켜기·끄기
- `test/` : 자동 테스트 (`npm test`)
- `docs/` : 설계 문서와 구현 계획
- `pool/`, `data/`, `selected/`, `config.json` : 사진·투표 데이터·개인 설정 (GitHub에 올리지 않음)

## 첫 설정
1. `config.example.json`을 `config.json`으로 복사합니다.
2. `config.json`의 `adminLogin`에 본인 Tailscale 로그인 주소를 적습니다.
   `publicBase`에는 이 PC의 Tailscale 주소를 적습니다. 예: `https://my-pc.example-tailnet.ts.net:10000`
   (`tailscale status --json`의 `Self.DNSName`에서 확인할 수 있습니다.)
3. `npm run funnel:off`를 한 번 실행합니다. 포트 10000을 tailnet 전용 serve로 설정합니다.
   (`tailscale serve --bg --https=10000 http://127.0.0.1:8790`와 같은 설정입니다.)

## 한 주 사용 순서
1. `npm start`로 서버를 켭니다.
2. 관리 화면에서 사진을 올립니다.
3. 관리 화면에서 투표를 시작합니다.
4. `npm run funnel:on`으로 공개 접속을 엽니다.
5. 투표 링크를 전달합니다.
6. 투표가 끝나면 결과를 확인합니다.
7. `npm run funnel:off`로 공개 접속을 닫습니다.

관리 화면: `<publicBase>/admin` (예: `https://my-pc.example-tailnet.ts.net:10000/admin`)

## 갤러리에서 공유로 올리기

1. 갤럭시 Chrome에서 관리 페이지를 열고 메뉴에서 **홈 화면에 추가** 또는 **앱 설치**를 선택합니다.
2. 삼성 갤러리에서 사진을 선택하고 **공유**를 누른 뒤 **아기사진**을 선택합니다.
3. 관리 앱에서 분석 결과를 확인하고 사진을 올립니다.

갤러리의 공유 시 HEIF 변환 설정이 켜져 있으면 JPG로 전달되며 그대로 올릴 수 있습니다.

## 백그라운드 실행 (Windows)
- 명령 프롬프트: `start /min node server.js`
- PowerShell: `Start-Process -WindowStyle Minimized node server.js`

## 안전 수칙
- funnel은 투표 기간에만 켭니다.
- 투표가 끝나면 반드시 `npm run funnel:off`를 실행합니다. 끝난 주의 투표 링크는 이때 자동으로 폐기됩니다.
- `tailscale serve reset`은 절대 실행하지 않습니다. 다른 포트(443, 8443)의 설정이 함께 지워집니다.

## 명령어
- `npm run funnel:on` : 투표 기간용 공개 접속(Funnel)
- `npm run funnel:off` : tailnet 전용으로 전환하고, 끝난 주의 투표 링크를 폐기
- `npm run funnel:status` : 포트 10000 현재 상태 확인

스크립트는 443, 8443 포트 설정을 건드리지 않으며, 그 설정이 바뀌면 exit 1로 중단합니다.
